# Ideal Café

Welcome to **Ideal Café**, a simple and elegant café-themed website built using **React.js**. This project is a frontend web application that showcases an online café experience, complete with interactive pages, menu browsing, cart management, and a responsive layout.

## Features

- **Responsive Navigation Bar**  
- **Home Page** with a carousel and feature cards  
- **Menu Page** with filter and sort functionality  
- **Add to Cart** and **Cart Page** to manage selected items  
- **Checkout Page** for simulating orders  
- **Locations Page** to show café outlets  
- **Contact Us Page**  
- **Special Offers Page**  
- **Sign In Page** (UI only)  
- **Interactive Recommendations Section**  
- **Daily Ice Cream Feature**  
- **User Reviews Section**

## Tech Stack

- **React.js** (frontend framework)
- **React Router** (for client-side routing)
- **React-Bootstrap** & **Bootstrap** (for responsive UI)
- **React Icons** (for icons only)
- **Custom CSS** (for styling)
